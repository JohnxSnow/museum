# کۆشکی شاهانەی شاکارە جیهانی و کوردییەکان (180m Imperial Virtual Art Palace)

گەورەترین و پێشکەوتووترین مۆزەخانەی مەجازی سێ ڕەهەندی (3D WebGL / Three.js) بە ڕووبەری **١٨٠ مەتر بە ١٨٠ مەتر**، لەگەڵ **٥٦ تابلۆ و شاکاری بەناوبانگی جیهانی، سوریالیزم، ئەقڵتەزێن و کەلەپووری دێرینی کوردستان بە وێنەی ئەسڵی و کوالیتی بەرز (HD)** لەگەڵ دیزاینی شاهانە، تیشک و ڕووناکی مۆدێرن، و پشتگیری تەواو بۆ **مۆبایل، تابلێت و کۆمپیوتەر**.

---

## 🏛️ تەلارسازی و دیزاینی کۆشک (١٨٠م × ١٨٠م)

1. **ڕووتۆندای ناوەندی (Central Rotunda & Dome):**
   - گومەزی زێڕینی ١٨ مەتری لەگەڵ پەنجەرەی ئۆکولیۆس (Oculus).
   - تاڤگەی کریستاڵ و پەیکەری زێڕین لە ناوەندا لەگەڵ دەنگی ئاوی سروشتی.
   - چریکەی تیشکی خودایی (Volumetric Light Rays) کە لە گومەزەوە دەدرەوشێتەوە.
   - زەوی مەڕمەڕی ڕەشی پۆڵیشکراو (Nero Marquina) بە دەماری زێڕینی کاڵاکاتا.

2. **٨ هۆڵ و باڵی شاهانە بە دیزاینی جیاواز:**
   - **هۆڵی باکوور (North Hall):** شاکارەکانی ڕێنیسانسی باڵا (مۆنا لیزا، دروستکردنی ئادەم، شێوی کۆتایی، قوتابخانەی ئەسینا).
   - **باڵی باکووری ڕۆژهەڵات (North-East Pavilion):** سەردەمی زێڕینی هۆڵەندا و بارۆک (کچێک بە گوارەی یاقووت، ئێشکگری شەوانە، لاس مێنیناس، ئارنۆلفینی).
   - **هۆڵی ڕۆژهەڵات (East Hall):** ئیمپڕێشنیزمی فەڕەنسی و تیشک (شەوی ئەستێرەباران، گوڵەبەڕۆژەکان، کافێی شەوانە، نیلووفەرە ئاوییەکان).
   - **باڵی باشووری ڕۆژهەڵات (South-East Pavilion):** خاڵکاری و بۆتیچێلی (ئیمپڕێشن خۆرهەڵاتن، لەدایکبوونی ڤینۆس، ژنێک بە چەترەوە، دوورگەی گراند ژات).
   - **هۆڵی باشوور (South Hall):** مۆدێرنیزم، ئێکسپرێشنیزم و سیمبۆلیزم (ماچەکە، هاوار، شەپۆلە مەزنەکەی کاناگاوا، ئازادی ڕێبەری گەل دەکات، گۆتیکی ئەمریکی، نایت هۆکس).
   - **باڵی باشووری ڕۆژئاوا (South-West Pavilion) - هۆڵی سوریالیزم، خەیاڵ و ئەقڵتەزێن:**
     - کاتی بەردەوام / کاتژمێرە تواوەکان (سەلڤادۆر دالی)
     - کوڕی مرۆڤ / سێوی سەوز و کڵاوی ڕەش (ڕێنێ ماگریت)
     - فریودانی وێنەکان / Ceci n'est pas une pipe (ڕێنێ ماگریت)
     - گۆڵکۆندا / بارانی پیاوانی کڵاودار (ڕێنێ ماگریت)
     - ڕێژەیی / پلیکانە مەحاڵە بێ کۆتاییەکان و دژە-کێشکردن (مۆریتس ئێشەر)
     - دەستە وێنەکێشەکان / پارادۆکسی دروستبوون (مۆریتس ئێشەر)
     - تاڤگەی ئەبەدی / جووڵەی نەبڕاوە (مۆریتس ئێشەر)
     - باخچەی چێژە زەمینییەکان (هیرۆنیمۆس بۆش)
     - فیلە باڵابەرزەکانی سەر پێی جاڵجاڵۆکە (سەلڤادۆر دالی)
     - ڤێرتۆمنۆس / ڕوخساری میوە و گوڵەکان (جۆسێپێ ئارچیمبۆڵدۆ)
     - خەون / جیهانی نهێنی و ئەفسووناوی دارستان (ئەنری ڕوسۆ)
     - کەوتنی فریشتە یاخییەکان (پیتەر برۆگلی باوک)
     - خەوی عەقڵ دەعبا دەخوڵقێنێت (فرانسیسکۆ گۆیا)
     - سایکڵۆپس / چاوە گەورە ئەفسانەییەکە (ئۆدیلۆن ڕێدۆن)
     - نهێنی و پەژارەی کۆڵانێک (جۆرجیۆ دێ کیریکۆ)
     - گەڕۆک لەسەرووی دەریای تەمەوە (کاسپار دەیڤید فریدریش)
   - **هۆڵی ڕۆژئاوا (West Hall) - کۆشکی کەلەپوور و شارستانیەتی کوردستان:**
     - قەڵای دێرینی هەولێر (٦٠٠٠ ساڵ نیشتەجێبوونی بەردەوام - یونسکۆ)
     - قەڵای مێژوویی کەرکووک و تەپۆڵکەی ئاراپخا
     - ئەشکەوتی شانەدەر (گۆڕستانی گوڵی نیاندەرتاڵ لە برادۆست)
     - پەرستگای پیرۆزی لالش و قوبە قوچەکییە پیرۆزەکان
     - فەرش و مافووری ڕەسەنی دەستچنی هۆزەکانی کوردستان
     - جلوبەرگی شاژنانە و فۆلکلۆری کوردی
     - ئاهەنگی مەشخەڵی ئاگری نەورۆزی ئاکرێ
     - تەلارسازی بەردینی هەورامان (یونسکۆ)
     - لووتکە سەرکەشەکانی چیای زاگرۆس
     - کۆچەرییەکانی زاگرۆس و کۆچی باوان
   - **باڵی باکووری ڕۆژئاوا (North-West Pavilion) - مێزۆپۆتامیا و ئاسەوارە دێرینەکان:**
     - دەروازەی شکۆداری عەشتاری بابیلۆن (مۆزەخانەی پێرگامۆن، بەرلین)
     - ڕێڕەوی کاروانی بابیلۆن و شێری زێڕینی نەخشێندراو
     - تاتەبەردی لافاوەکەی گیلگامێش بە پیتی بزماری (نەینەوا / مۆزەخانەی بەریتانی)
     - قاپە زێڕینەکەی حەسەنلوو (زێڕی پەتی و میتۆلۆژیای زاگرۆس)
     - تاقی کەسرا / کەوانەی مەدائین (گەورەترین کەوانەی خشتی جیهان)
     - تاقی وەسان / نەخشەبەردینەکانی شاخی کرماشان
     - پەیکەری شێری بەردینی بابیلۆن
     - تابلۆی ژیانی فۆلکلۆری و دەنگبێژانی کورد

## 🚀 شێوازی کارپێکردن

1. دوانەکلیک لەسەر فایلی `run_gallery.bat` یان `start.bat` بکە.
2. یان لە تێرمیناڵ بنووسە:
   ```bash
   node server.js
   ```
3. وێبگەڕەکەت دەکەوێتە کار لەسەر ناونیشانی:
   ```
   http://localhost:3000
   ```

## 🎮 کۆنتڕۆڵ و بەکارهێنان

- **جووڵە:** دوگمەکانی `W, A, S, D` یان تیرەکانی کیبۆرد.
- **ڕاکردن:** دوگمەی `Shift`.
- **بازدان:** دوگمەی `Space`.
- **سەیرکردنی تابلۆ:** بە دوگمەی `E` یان کلیک لەسەر هەر تابلۆیەک.
- **گەشتی سینەمایی بەناو کۆشکدا:** دوگمەی `C` یان کلیک لەسەر دوگمەی 🎥.
- **گۆڕینی کات و کەشوهەوا:** دوگمەی `L` (ڕۆژ، خۆرئاوا، شەو).
- **میوزیک و دەنگی سروشت:** دوگمەی `M` (پیانۆی ئارامکەرەوە و دەنگی فوارە).
- **گواستنەوەی خێرا (Teleport):** لە لیستەکەدا کلیک لەسەر هەر هۆڵێک بکە.
- **کامێرای وێنەگرتنی سینەمایی (Photo Mode):** دوگمەی `P` یان دوگمەی 📷 لە سەرەوە (گرتنی وێنەی Full HD بە زووم، فلتەرەکانی سینەمایی، ڤینتیج، ڕەش و سپی، و لۆگۆی شاهانە، لەگەڵ داگرتنی خێرا).
- **ڕێکخستنی کواڵیتی گرافیک:** دوگمەی ⚙️ لە سەرەوە بۆ گۆڕینی کواڵیتی (🚀 خێرا بۆ مۆبایلی لاواز، ⚖️ هاوسەنگ، و 👑 شاهانە بۆ بەرزترین ڕوونی).
- **پشتگیری مۆبایل:** جۆیستیکی تایبەت لە خوارەوە بۆ جووڵە، پەنجە ڕاکێشان بۆ سەیرکردن، و دوگمەی 👁️ بۆ بینینی تابلۆکان.
